# Unit 6 Discussion: Dictionaries as Hash Tables

## Overview

This assignment uses Python dictionaries to demonstrate hash table behavior.

## Learning Objectives

- Insert key-value pairs
- Retrieve values efficiently
- Update existing values
- Remove entries
- Understand hashing concepts

## Requirements

1. Create and populate a dictionary.
2. Demonstrate lookup operations.
3. Demonstrate update operations.
4. Demonstrate delete operations.
5. Test edge cases.
6. Create a real-world scenario.

A challenge I encountered was working with a student who wasn't in the dictionary. I overcame this by looking up a missing key and checking to see if
the student existed before deleting the key-value pair. This allowed me to test edge cases without trying to delete a student who wasn't in the
dictionary.

Hash tables behave by storing information as key-value pairs and allow values to be retrieved using their keys. Collisions are when keys map to the 
same location. Hash tables can improve efficiency by allowing values to be retrieved instead of checking each individual value one at a time.
