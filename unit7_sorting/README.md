I learned how Bubble Sort and Merge Sort can both be used to sort values in a list. I learned that Bubble Sort compares values next to each other and swaps them
when they are out of order. I also learned that Merge Sort divides a list into smaller halves and then merges them back together in the correct order.
Merge Sort was more challenging for me because I had to understand how to divide the list into smaller halves and then merge the values back together. I overcame
this by working through each part of the algorithm one step at a time and testing the program to make sure it worked correctly.
Bubble Sort is easier to understand and implement, but it is less efficient when sorting larger amounts of data because it is more complicated and requires more
memory. Bubble Sort would be better for smaller lists, while Merge Sort would be better for larger lists.
